# 小学课程与累计掌握

离线课程覆盖汉字、拼音、英语和数学，按小学一至三年级的学习主题组织单元。汉字以 GB2312 一二级汉字为边界；英语全部字段中的英文词均以固定版本 NGSL 原形白名单为边界，不设字母或专名例外。课程卡数、独立汉字数、独立英语词数和未完成的审校项目分别报告，不能用同一词的双向题或重复选项充当独立词数。完整课程为 4000 张、135 个单元，其中汉字 2200、拼音 150、英语 450、数学 1200；英语对应 225 个学习词。具体内容与来源见[内容说明](../content/README.md)。

## 学习与进度

- 家长设置 → 学习设置可以选择每轮 5 / 10 张，以及学会门槛 1 / 3 / 5 / 7 / 9 次；默认 5 张、3 次。
- 只有“选一选”答对才累计一次。同一卡片同一轮最多累计一次；翻面、浏览、跳过、回看和反复按键均不累计。正确次数跨轮、跨保存恢复累计，答错保留之前的正确次数。
- 达到门槛后标记已学会，后续普通学习与“再看看”均跳过该卡。提高门槛保留已经学会的结果；降低门槛时，已有正确次数达到新门槛的卡片立即学会。
- 每科独立解锁单元。当前单元至少 80% 卡片学会后开放下一单元，所需张数向上取整；未完成的旧卡仍可抽到，已解锁单元不会因修改设置而关闭。
- 普通轮次按错题、新卡、学习中的卡片交错抽取；候选不足时由其他类别补足，不在同一轮重复同一张卡。剩余不足 5 / 10 张时使用较短轮次。选项位置每轮重排，保存后恢复同一轮的顺序。
- 家长设置 → 学习设置 → 选择学习起点可以分别为四科选择单元。二次确认默认取消；选择起点开放到该单元，不把前面卡片标为学会，已开始学习的旧卡仍保留。重置会清除四科进度、起点、解锁状态和当前轮次，保留每轮张数及门槛。

“已学会”表示设备记录到了指定次数的四选一正确答案，不能代替朗读、书写、理解或口语能力评价。

## SD 课程包

构建后把 `.build/sdcard/` 中的 `balabala` 目录复制到 SD 根目录，课程文件位置为：

```text
/balabala/curriculum/course.bin
/balabala/curriculum/manifest.json
```

课程正文与固件内目录必须属于同一次构建。`manifest.json` 用于人工核对数量、版本、长度和 CRC，不是运行时可执行代码。复制时同时保留 `NOTICE.md` 和 `attribution/`，其中包含数据归属、完整许可、固定来源锁及人工源。更新前先备份 `/balabala/saves/`；设备完成保存并关机后再操作 SD，安全弹出后装回设备。运行中不支持自动热插拔或重新挂载。

没有课程包时可使用四科内置示范卡。若原存档来自完整课程，课程缺失、损坏或与固件不匹配会保护原存档并停止导出；临时学习、返回、重置或重新初始化存储均不能解除保护。修复匹配的课程包并重新恢复有效存档后才可继续保存。单卡正文在启动验证后发生损坏，同样显示可退出错误并保护存档。

自定义小卡组继续使用[原 JSON 导入接口](learning-app.md#内容包)，但完整课程模式不叠加这些小卡组；完整课程以自身稳定 ID 和目录为准。

## 文件与运行内存

固件 Flash 保存只读卡片目录、稳定身份、单元、正文偏移和每卡 CRC。启动时以 256 字节块校验整包长度、版本与 CRC；学习期间仅按需读取本轮最多 10 张正文，每张最多 2048 字节，并再次校验单卡 CRC、内容与排版。正文不随全部课程常驻 RAM。

课程进度每卡使用一个字节，目录上限 4096 张；选项排列、游标、轮次、门槛和单元状态一同保存。原有 32768 字节双槽上限、32768 字节活动内容计费、83807 字节字体逻辑构造门禁、65536 字节主栈、48000 字节帧缓冲和 7680 字节条带仍适用。Flash 目录、字体大小和实际运行 heap 的口径不同，链接表剩余空间不能视为可用 heap。

`course.bin` 为 16 字节头和逐卡 UTF-8 JSON 正文：头依次为 `BALC`、LE u32 格式版本 1、LE u32 正文长度、LE u32 正文 CRC32。目录由同一构建生成，不接受把任意 JSON 改名为课程包。

## 双槽迁移

新导出使用 `BALA` 版本 2 的 24 字节记录头，保留 generation、payload 长度和 CRC32 契约。payload 包含长度前缀的轮次/设置 JSON 与稀疏课程进度；每条课程进度为稳定 32 位键和 1 字节标记，4096 条最多 20480 字节。身份键在构建时检查碰撞，目录重排不按数组位置迁移进度。整个存档仍不得超过 32768 字节。

版本 1 记录仍可读取。旧“认识了”仅迁移为一次正确，旧待复习迁移为待复习，不把历史上缺少次数证据的卡片直接标为学会；可解释的原轮次 ID、游标与已答结果保留。现有 128 张示范使用的 ID 均进入完整课程。相对改动前示范，125 个旧 ID 延续；不在 NGSL 白名单的水果卡 `english-01` / `english-02` / `english-03` 明确退役，替换词采用新 ID，旧证据不转给不同词。完整课程恢复含退役卡的旧轮次时结束该轮，保留其他已知卡进度；缺少完整课程时不可用该退役规则绕过原档保护。

加载先选择 CRC、长度与语义有效的最高 generation，再检查课程身份和当前资源是否可解释。最高有效档包含未知课程、未知稳定键、课程不匹配或未成功读入资源时必须保护原档，不能用更旧的槽隐藏问题。保护清除待确认事务，迟到保存 ack 无效。双槽与 CRC 用于恢复和意外损坏检测，不提供掉电原子性或内容认证。

## 验证边界

行为验证、构建尺寸和 PBM 检查见[验收记录](acceptance.md)。宿主替身验证不等于真实 SD、RTOS 或无线环境；完整课程的动态 heap、最大连续块、任务栈高水位、连续学习、取卡故障及掉电恢复仍须设备验证。没有对应证据时不把内容编译、链接或离线渲染通过描述为真机验收完成。
