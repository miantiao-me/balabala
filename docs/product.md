# 产品设计草案

首版支持四科离线学习、SD 课程与存档、家长设置和 BLE 配网。本文定义交互与内容规则；操作步骤见[使用说明](usage.md)，实现入口见[代码结构](architecture.md)。当前部署与待验边界以[最新验收](acceptance.md)为准，旧候选证据保留在对应历史章节。

## 产品定位

扒拉扒拉让孩子拿起设备即可看一组卡片，让家长能挑选内容、陪孩子表达，并把需要再看的卡片留下来。支持亲子共学，并按小学一至三年级主题逐步开展汉字、拼音、英语和数学练习。

- 离线完成选卡组、翻卡、练习和复习；首版联网只用于家长配网，内容通过 SD 卡导入。
- 一轮默认 5 张，可选 10 张，随时结束。完成页展示“看过的卡片”和“下次再看”，不做排行榜、连续签到压力或惩罚。
- 首版以静态图文为主；不把发音、录音、触摸或彩色反馈作为必要条件。拼音和英语的发音由家长示范，后续可评估手机伴读。

## 页面与学习闭环

首页提供“开始 / 继续”大卡和汉字、拼音、英语、数学四个入口。进入学科后选择“认一认”“选一选”或“再看看”；没有待复习卡时，“再看看”显示空态并跳过选择。家长在首页按住正面第三键“返回”2 秒进入设置。

提供“认一认”和“选一选”两种模式：

- **认一认**：侧面上下键浏览知识卡，正面确认键翻面，展示答案与一句例子；浏览和翻面不评分。
- **选一选**：每题四个选项，正面四键 A/B/C/D 直接作答；提交后显示反馈，按侧面下键继续，不自动跳题。
- 答对展示鼓励图案与简短文案；答错加入“再看看”，不做惩罚反馈。两种反馈均反白正确选项并保留解释。
- 侧面翻题可跳过，跳过不计答错；回看已答题保留结果，不重复评分。
- 完成页按本轮结果显示星星和“再看看 / 再来一轮”，不自动跳转。电源短按回首页后可继续原轮次；保存成功后，重启也可继续。

无完整课程包时，每科有 32 张内置示范卡，共 128 张。完整课程按年级和单元递进，安装与掌握规则见[课程说明](curriculum.md)，自定义小卡组见[内容包](learning-app.md#内容包)。答题结果用于安排复习，不作为能力诊断。

汉字练习呈现大字、拼音和词语；拼音需校对声调、ü 与字形；英语不提供口语评分；数学从数量对应与 10 以内加减展开，不使用倒计时。首版卡组以文字为主，每道练习题有四个不同选项和唯一正确答案，不做未经校验的笔顺动画。

## 按键方案

按物理位置分配：侧面电源与上下键，正面四键从左到右编号 1–4。驱动中的逻辑键名与物理位置、电气读取方式仍需实机核对。

| 按键 | 四选一答题页 | 非答题页 |
| --- | --- | --- |
| 侧面电源短按 | 保存进度，回桌面 | 回桌面 |
| 侧面电源长按 | 保存进度，关机 | 保存进度，关机 |
| 侧面上 / 下 | 上一题 / 下一题，不计作答 | 上下选择或翻页 |
| 正面第 1 键 | A | 左 |
| 正面第 2 键 | B | 右 |
| 正面第 3 键 | C | 返回 |
| 正面第 4 键 | D | 确认；知识卡中翻面 |

- 正面四键提示始终显示在屏幕底边，按实体位置对应；未答题显示 A/B/C/D，非答题页显示左/右/返回/确认。已答题反馈页使用非答题映射：左右回看/前进、返回回桌面、确认主动进入下一题或轮末总结；侧面上下仍可翻题，不重复评分。
- 短按完成孩子的全部学习操作；家长区仅从首页按住“返回”2 秒进入，返回键帽只显示返回图标。长按从其他页面回到首页时不会顺带打开家长区，须松开后重新长按。
- 电源短按在松手时判定；长按 1500ms 只产生关机请求。平台尝试保存并等待网络资源释放，条件满足后全刷静态休眠图（月亮图案竖直居中，文字在下方），再让屏幕与 MCU 进入休眠；保存失败时保留错误提示。独立硬件复位键仅用于复位。实际功耗、唤醒及实体键位仍待真机核验。
- USB 供电时不自动休眠；拔线后无操作满 5 分钟才尝试保存并深度休眠。按键延后计时，配网、刷机、刷新和输入 / 无线清理故障会阻止自动休眠；保存失败或无卡时保留页面与提示。手动关机沿用原失败处理，完整操作见[省电与自动休眠](usage.md#省电与自动休眠)，平台时序见[主循环、保存与关机](platform.md#主循环保存与关机)。
- 新题显示完成且上一按键已释放后才接受作答；每题每轮只记录一次结果，反馈页连按不得穿透到下一题。导航可合并到最终目标，不能积压逐帧刷新。
- 首版不依赖组合键；若硬件复用 ADC，先验证同时按下是否可区分。

## 屏幕设计

竖屏逻辑布局为 480×800，物理面板为 800×480。首页、学科、学习、家长区及错误页各有独立布局，以大字、留白、描边和反白区分层级。根据原版 X4 实拍照片进行透视校正后，正面四键的列中心设为 x=90 / 185 / 295 / 390，导航键帽和答题列共用这组坐标；仍需正视真机核验。首页顶部留白，不显示产品名称。

```text
┌────────────────────────┐
│ 字                ●○○○○│
│                        │
│    哪个字表示高山？     │
│                        │
│ ┌────┐┌────┐┌────┐┌────┐│
│ │ 山 ││ 水 ││ 火 ││ 木 ││
│ │ A  ││ B  ││ C  ││ D  ││
│ └────┘└────┘└────┘└────┘│
└────────────────────────┘
```

字号使用 24px Regular、32px Regular、48px Bold 和 176 / 112px 特大字。认一认优先特大字，内容放不下时退到 48px 折行；选项整题统一使用能完整排下四项的最大字号。均衡折行保留西文单词与数字，最小字号才允许逐字拆词。

- 学习时不滚动跑马灯、不闪烁光标、不展示实时秒表；作答后刷新一次结果页，鼓励图案与答案一起呈现，不做逐帧动画。
- 答对从 12 幅原创 SVG 黑白鼓励图中轮换（太阳、星星、动物、花草、火箭和风筝等），配简短鼓励语；正确选项反白。每题只展示一幅，同轮不重复，跨轮换图；回看或读档后继续同一题时保留原图。反馈停留到孩子主动翻页，不依赖 emoji 字体。
- 答错温和展示“我们一起看看”和正确答案，不用哭脸、惩罚叉号或扣分动画。
- 普通页面之间切换、翻面和换卡优先局刷；默认连续 8 次局刷后全刷清理残影，家长可选 8 / 16 / 32 / 64 / 128 次；间隔越长，残影可能越明显。开机、进出配网、刷机、错误和休眠页仍全刷，显示失败后的重试也全刷；实际残影和刷新耗时仍需真机验证。
- 字体按卡组所需字符离线制作；验证汉字、拼音组合符号与预组字符、英语和数学符号覆盖，缺字在导入时提示。

## 复习与内容

- 使用“新卡 / 学习中 / 已学会”三种状态，另标记待复习。默认累计答对3次学会，可选1 / 3 / 5 / 7 / 9次；答错不清除正确次数，学会后退出后续抽题。单元学会至少80%后解锁下一单元，普通轮次交错安排错题、新卡和未学会卡片；本轮不重复评分。家长设置第二项“学习情况”展示四科数量和黑白进度条。
- 首版按学习轮次安排复习，不依赖准确日历时间；联网授时后再评估按天的间隔复习。
- 卡片使用稳定 ID；四选一选项须不同且答案有效。更新同 ID 卡片时保留进度，字段、版本和导入校验统一见[内容包](learning-app.md#内容包)。
- 课程放在 SD 卡，按轮读取；字体离线构建，不将全部正文常驻 RAM。缺卡或坏卡时提供可返回的错误页。
- 家长可以在“学习设置”中选择每轮数量、学会门槛、四科学习起点和清屏间隔，并查看学习情况。家长区第六项展示三页课程来源与编排说明，完整归属和许可随 SD 课程包提供。重置前须用 A/B/C/D 连续答对 3 道家长算术题，再进入默认取消的最终确认；答错或短按电源即取消，退出后须重新验证。确认后清除四科进度、当前轮次和轮换位置，保留卡组、每轮数量、学会门槛及清屏间隔，操作见[重置学习进度](usage.md#家长设置)。存档受保护时不覆盖原文件，须先修复资源并恢复，见[双槽存档](learning-app.md#双槽存档)。
- 首版支持本地卡组拷贝；Wi-Fi 内容传输可后续增加。应用代码与内容包分开，不把下载内容当可执行 JS。

## 刷机模式

家长设置第五项为刷机模式，第四项为蓝牙配网。二次确认默认取消；准备中可返回或短按电源取消，长按关机优先。最终画面仅显示白底居中的 `Download Mode` / `Keep USB connected`。只读 eFuse 预检、保存、一次网络取消、精确显示确认和 ROM 切换顺序统一见[刷机模式](download-mode.md#进入条件与顺序)。

## 蓝牙配网

家长开启限时 BLE 配网后，设备先保存未保存进度，再显示准备面板、设备名和本次 6 位数字配网码；保存失败不启动无线，无未保存进度时不强制写卡。“连手机”反白才表示广播成功，手机使用乐鑫官方 iOS 客户端和 Security 1 提交 Wi-Fi 凭据。

成功、取消或超时后关闭入口，返回、回首页和关机均等待明确资源释放。资源可能驻留的清理失败须保留固定面板和按键响应，撤销关机、锁止重开，暂停学习渲染及自动保存。资源已释放但旧配置恢复失败时可退出错误页，本次开机仍禁止重开。

两次准备帧的全刷确认、View/UI 释放、活跃期面板更新和终态身份擦除统一见[分阶段配网](staged-provisioning.md)；操作、时限、安全和生命周期见[BLE 配网](ble-provisioning.md)。身份只有实际刷新后才视为从物理屏擦除，显示失败不能保证擦除。

首版不包含 Android 专项交付、自有手机应用或无线内容导入；常态学习关闭不必要的无线连接。
