# 使用说明

设备可离线学习汉字、拼音、英语和数学，不配网也能翻卡、答题。四科各有 32 张内置示范卡，共 128 张；完整的 4000 张课程通过 SD 卡安装，SD 卡也用于保存进度。安装方法见[课程说明](curriculum.md#sd-课程包)，当前验证范围见[最新验收](acceptance.md)。

## 开始一轮学习

1. 在首页选择学科，确认进入卡组。首页“开始”可直接进入汉字认读；已有轮次时显示“继续”。
2. 选择“认一认”或“选一选”。默认每轮 5 张，家长可改为 10 张。
3. “认一认”用确认键翻面，侧面上下键看前后卡片。翻面、浏览和跳过均不评分。
4. “选一选”用正面四键选择 A、B、C、D。答对显示静态黑白鼓励图案，答错显示答案和解释；反馈停留到孩子主动翻题。
5. 反馈页按侧面下键或确认进入下一题，侧面上键回看。回看保留原结果，同题每轮只评分一次。

轮末可选“再看看”复习错题，或“再来一轮”。学科页也有“再看看”，没有待复习卡时会跳过该选项。短按电源回首页后可选“继续”；保存成功后，重启也可继续。

默认跨轮累计答对 3 次学会，答错保留已有正确次数。已学会卡片不再抽取，当前单元学会至少 80% 后解锁下一单元。这里的“学会”只表示四选一答对次数，不能替代朗读、书写或理解能力评价。

普通浏览和翻页优先局刷；默认连续 8 次局刷后全刷清理残影。家长可在“学习设置 → 清屏间隔”依次选择 8 / 16 / 32 / 64 / 128 次，保存成功后重启保留。次数按实际刷新累计，菜单移动、答题反馈和换题都可能计一次；间隔越长闪屏越少，残影可能越明显。开机、休眠、配网和刷机等关键页面仍保留全刷。

## 按键

正面四键按机身从左到右编号。下表为逻辑映射，默认 ADC 分段与实体键序仍待真机核验，请按屏幕变化和底部提示核对。

| 按键 | 未答四选一 | 其他页面及已答反馈 |
| --- | --- | --- |
| 正面第 1 / 2 键 | A / B | 左 / 右，选择或翻页 |
| 正面第 3 键 | C | 返回；首页按住 2 秒进入家长设置 |
| 正面第 4 键 | D | 确认、翻面或主动下一题 |
| 侧面上 / 下 | 上一题 / 下一题，不评分 | 上下选择或翻页 |
| 电源短按后松开 | 回首页，保留本轮 | 回首页 |
| 电源长按 1.5 秒 | 请求保存并休眠 | 请求保存并休眠 |

新题显示完成且上一按键松开后，才接收正面按键；不要在刷新时按住答案键等待触发。长按电源不会先执行短按，独立 Reset 键仅用于复位。

关机时先保存、完成网络清理，再显示“睡觉啦”并休眠；保存失败会保留错误提示。真实休眠、唤醒和键序仍待验证。

## 家长设置

在首页按住正面第三键“返回”2 秒进入，键帽只显示返回图标。须在首页开始长按；从其他页面按住返回到达首页后，要先松开再长按。

| 顺序 | 设置项 | 用途 |
| --- | --- | --- |
| 1 | 学习设置 | 每轮张数、学会门槛、四科起始单元、清屏间隔 |
| 2 | 学习情况 | 查看四科已学会、学习中和新卡数量 |
| 3 | 重置学习进度 | 连答 3 道家长算术题后，再明确确认；默认取消 |
| 4 | 蓝牙配网 | 用官方 iOS 客户端配置 Wi-Fi，见下文 |
| 5 | 刷机模式 | 进入维护用下载入口，见下文 |
| 6 | 课程来源 | 查看汉字读音、英语词表和项目编排说明；侧面上下翻页，返回或确认退出 |

家长菜单一次显示五项，向下选择可看到第六项“课程来源”。汉字读音来自 Unicode Unihan 18.0.0，英语词表来自 NGSL 1.2（2023），其余内容由项目编排或校订；完整许可和修改归属随 SD 课程包的 `NOTICE.md` 与 `attribution/` 提供。来源与使用边界见[课程许可](../licenses/curriculum.md)。

提高学会门槛不会撤销已学会结果；降低门槛后，正确次数已达标的卡片立即学会。选择学习起点也须二次确认，只开放到指定单元，不把前面的卡片标为学会。

重置前会依次显示 3 道两位数乘法加数题，用正面 A/B/C/D 作答；题目显示完成、松开上一按键后才接收答案。答错立即退出，短按电源可随时取消；第三键在题面是答案 C，不能当返回键使用。三题全对后进入最终确认，默认选择取消，须另行选中重置并确认；退出或重启后要重新答题。

重置会清除四科进度、起点、解锁状态、当前轮次和轮换位置，保留卡组、每轮张数、学会门槛及清屏间隔。验证题不计入学习记录；存档受保护时，重置也不会覆盖原文件。

## 省电与自动休眠

连接 USB 电源时不自动休眠，充满但未拔线也一样。拔线后重新计时，无按键操作满 5 分钟才尝试保存、显示“睡觉啦”并深度休眠。接电时仍可长按电源手动关机。

按键按下、松开和长按都会延后计时；配网、刷机和屏幕刷新期间暂停计时，结束后重新计时。无 SD、保存失败或存档受保护时，会取消自动休眠并保留页面与提示，仍可继续学习。手动关机即使保存失败也可能休眠，请先留意提示。

静置时处理器自动降频，不影响页面和按键。设计上可按电源键唤醒并继续已保存进度；实际续航和自动休眠后的唤醒仍待真机测量，软件结果见[省电验收](acceptance.md#省电优化验收)。

## SD 卡与进度

### 安装课程或自定义卡组

完整课程按[SD 课程包](curriculum.md#sd-课程包)安装，须与固件来自同一次构建。完整课程模式不叠加自定义小卡组。

没有完整课程包时，可将四个 UTF-8 JSON 小卡组放在 SD 卡根目录下：

```text
/balabala/decks/hanzi.json
/balabala/decks/pinyin.json
/balabala/decks/english.json
/balabala/decks/math.json
```

示例源：[汉字](../content/hanzi.json)、[拼音](../content/pinyin.json)、[英语](../content/english.json)、[数学](../content/math.json)。修改时保留 `subject`，以稳定的卡片 `id` 关联进度，更新同一卡组时增加 `version`。字段、字形与容量限制见[内容包](learning-app.md#内容包)；新增汉字可能需要重新构建字体，导入不会下载字体或执行应用代码。

操作 SD 卡前让设备保存并关机；编辑后安全弹出，再装回设备启动。不支持运行中热插拔后自动重挂载。小卡组文件缺失时保留内置 / 当前卡组；内容不合法或无法读取时提示错误，保留旧内容，可返回修正。

### 保存与恢复

进度自动写入 `/balabala/saves/slot0.bin` 和 `slot1.bin`，不要手工编辑。无 SD 可体验内置卡，但不能保存新进度。“存储不可用”或“保存失败”表示本次操作未必能在重启后恢复；双槽机制也不能替代真实 SD 掉电验收。

启动时存档未完整读出，或原进度依赖的课程 / 卡组未成功读入，设备会保护原存档，停止保存本次临时学习。返回首页、重置或重新初始化存储均不能解除保护；须修复 SD、装回匹配内容并重新成功恢复有效且可解释的存档。具体规则见[双槽存档](learning-app.md#双槽存档)。

## 蓝牙配网

1. 打开家长设置第四项，等待设备名、六格数字配网码出现，且“连手机”反白。
2. 在乐鑫官方 **ESP BLE Provisioning** iOS 客户端手动搜索同名设备，以 Security 1 输入当前 6 位配网码，保留前导 0。
3. 选择 Wi-Fi 并提交密码；设备显示成功后，等待手机读取结果和入口清理完成。

返回、回首页和关机也须等待网络清理。出现“清理失败”时不要反复要求重开，记录屏幕现象即可；反馈中不要包含 Wi-Fi 密码或配网码。旧 16 位配网码候选已有官方 iPhone 成功确认，当前 6 位配网码的手机交互仍待验收。完整操作与失败、取消、超时检查见[官方 iOS 路径](ble-provisioning.md#官方-ios-操作路径)。

## 刷机模式

家长设置第五项用于维护，二次确认默认取消。确认后等待保存、网络清理和最终两行英文 `Download Mode` / `Keep USB connected`，保持 USB 连接。准备中可返回或短按电源取消，长按关机优先。

入口不会自动烧录或擦除。进入 ROM 后应用停止响应按键，退出须按正常启动条件复位；设备、USB 和恢复边界见[刷机模式](download-mode.md)。
