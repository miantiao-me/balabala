# 离线课程内容

完整课程共 **4000 张、135 个单元**，按小学一至三年级主题递进；设备没有 SD 课程包时使用四科各 32 张的内置示范。年级与单元顺序是本项目教学编排，不对应某一版本教材，也不表示已经逐题人工审校。

| 科目 | 卡片 | 单元 | 一年级 | 二年级 | 三年级 | 学习目标口径 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 汉字 | 2200 | 70 | 626 | 959 | 615 | 2200 个不重复汉字，以主题词语呈现读音 |
| 拼音 | 150 | 5 | 150 | 0 | 0 | 声母、韵母、声调、整体认读、拼读与规则 |
| 英语 | 450 | 15 | 150 | 150 | 150 | 225 个词的识词与词义双向练习 |
| 数学 | 1200 | 45 | 400 | 400 | 400 | 数认知、运算、单位、图形、分数和时间 |

英语的 450 张不等于 450 个独立词；225 个学习词均来自固定 NGSL 原形白名单。不同方向的练习分别累计正确次数。汉字认读和四选一练习也不能代替书写、朗读、理解或实际表达能力评价。

## 可维护的人工源

- [课程大纲](curriculum/outline.json)：目标数量、各科依赖、数学主题题量和退役 ID。
- [识字主题词](curriculum/hanzi.tsv)：`年级|主题|词语列表`，按首次出现收录尚未覆盖的字，不按字符编码或 GB2312 顺序补齐。
- [词境读音](curriculum/readings.json)：覆盖 Unihan 默认读音与具体组词不一致的情况；修改主题词时需要同时检查多音字。
- [英语词义](curriculum/english.tsv)：`年级|主题|word=中文释义`，每词生成两个方向的卡片。
- [拼音规则](curriculum/pinyin.json)：拼音要素、声调、拼读示例和规则题。
- [来源锁](curriculum/sources.lock.json)：下载 URL、固定版本、实际计算的 SHA256 及许可依据。
- 四科原 JSON 保留小卡组导入格式。英语示范现使用 `water`、`bread`、`rice` 替换不在白名单的水果词，采用新 ID `english-water`、`english-bread`、`english-rice`；旧 `english-01`、`english-02`、`english-03` 明确退役，避免将旧掌握证据转给不同词。

完整课程保留现有示范中的 128 个 ID；相对改动前示范，有 125 个旧 ID 延续。已退役 ID 的进度不转给替换词；若旧轮次包含退役卡，恢复时结束该轮，已保留卡的进度仍可迁移。迁移及原档保护规则见[课程说明](../docs/curriculum.md#双槽迁移)。

## 构建、校验与安装

在仓库根目录执行：

```sh
sh tools/build.sh test
CARGO_PROFILE_RELEASE_OPT_LEVEL=z sh tools/build.sh build
```

构建入口下载并校验固定来源，仅在 `.tools/learning-data/` 保存上游数据，按人工源生成课程。每次生成重验原始文件 SHA256；报告缓存不能绕过验证。生成文件均放在忽略目录，不纳入 Git：

| 路径 | 用途 |
| --- | --- |
| `.build/curriculum/curriculum.json` | 可审阅的完整卡片与单元 |
| `.build/curriculum/curriculum-report.json` | 各科/年级数量、独立目标、词境、保留及退役 ID、字段上限、来源与未审校项目 |
| `.build/generated/course.rs` | 同次构建固件使用的只读课程目录 |
| `.build/sdcard/balabala/curriculum/course.bin` | 复制到 SD 的完整课程正文 |
| `.build/sdcard/balabala/curriculum/manifest.json` | 人工核对版本、数量、长度与 CRC |
| `.build/sdcard/balabala/curriculum/NOTICE.md`、`attribution/` | 随包分发的数据归属、许可、人工源及来源锁 |

关机后把 `.build/sdcard/` 中的 `balabala` 目录复制到 SD 根目录，和**同次构建**固件配套使用。更新前备份 SD 的 `/balabala/saves/`。课程正文不编入固件，设备只把本轮最多 10 张卡片读入 RAM；安装、存档和缺失资源处理见[课程说明](../docs/curriculum.md)。

读音源已升级至 Unihan 18.0.0，课程保持 4000 张卡、135 单元，稳定 ID 无增删。新版读音属性与词境读音修订使 1399 张汉字卡的选项变化；反面及解释只有 `hz-u5566`（哗啦中的“啦”）从 `la` 改为 `lā`。生成的 `course.bin` 为 874,632 字节、CRC32 `154bbdf2`，必须与同次构建固件配套使用。

生成器检查 ID、单元数量与顺序、四个不同选项、答案下标、字段字数/字节和卡片大小。**所有课程字段中的汉字**必须是 GB2312 一二级汉字，包含题干、释义及干扰项；英语卡全部字段中的英文词必须属于 NGSL 1.2 官方词目与补充表首列原形合并的 2859 词白名单，不推断词形，不设字母或专名例外。运行时另经真实内容解析器检查排版、字形与字体预算。

## 来源、许可与待审校项

NGSL 1.2 来自 Browne、Culligan、Phillips，英语课程数据及派生词表按 **CC BY-SA 4.0** 分发。Unihan 18.0.0 读音属性按 **Unicode License V3** 使用。下载、版本、摘要与完整许可见[课程数据归属](../licenses/curriculum.md)。主题词、词义、拼音规则及数学题为项目编排或运算生成，未复制教材题目。

自动约束检查和数学答案复算不能代替教学审校。多音字词境、英语释义及同义干扰项、适龄性、单元衔接、拼音示范和数学覆盖比例仍需逐题人工复核；实际设备的字体、连续学习、SD 故障、heap 与栈也仍需验收。对应状态以[验收记录](../docs/acceptance.md)为准。
